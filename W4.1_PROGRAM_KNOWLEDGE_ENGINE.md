# W4.1 PROGRAM KNOWLEDGE ENGINE GENERALIZATION

## 1. GENERALIZATION STRATEGY
The implementation of `Program Kokurikuler` has been successfully abstracted into the **Program Knowledge Engine**, allowing infinite specialized Program implementations with zero code duplication.

Instead of creating individual schemas, editors, and services for every school program, the system now relies on the `ProgramKnowledgeFactory` to generate specific variants driven entirely by the `EnterpriseKnowledgeType` registry entry.

## 2. FILES MODIFIED / CREATED
- `src/enterprise/knowledge/engine/program/models/ProgramKnowledgeModel.ts`: Generic `ProgramContent` and `ProgramActivity` definitions.
- `src/enterprise/knowledge/engine/program/services/ProgramKnowledgeService.ts`: Unified service layer creating documents based on their registry definitions.
- `src/enterprise/knowledge/engine/program/components/ProgramKnowledgeEditor.tsx`: Generic React component that renders dynamically depending on `capabilities` and `governmentPolicyTags` attached to the knowledge type.
- `src/enterprise/knowledge/engine/program/factory/ProgramKnowledgeFactory.ts`: Factory responsible for spinning up unique program variations without hardcoding logic.

## 3. SPECIALIZATION DIAGRAM

Each of these references the exact same React Editor and Document Service, but stores metadata specific to their domain and government policy tags (e.g., Supervisi does not load "8 Dimensi Profil Lulusan").
