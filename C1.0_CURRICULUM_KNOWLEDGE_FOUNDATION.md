# C1.0 CURRICULUM KNOWLEDGE FOUNDATION

## MISSION ACCOMPLISHED
Successfully established the strict Knowledge Foundation required by the Curriculum Hub. Designed and typed the Enterprise Knowledge Domains to serve as the unified source of truth for curriculum structure, without modifying any UI, KSP logic, or builder logic.

### KNOWLEDGE MODELS CREATED
The following knowledge interfaces have been defined in `src/enterprise/knowledge/models/curriculum/`:

1. **`CurriculumStructureKnowledge`**
   - **Knowledge Owner**: Curriculum Hub
   - **Government Source**: Kemendikdasmen Standar Isi (e.g. Kurikulum Merdeka)
   - **Validation Rules**: Must contain valid education levels and structural phase mapping.
   - **Payload**: `educationLevel`, `phase`, `curriculumType`.

2. **`LearningLoadKnowledge`**
   - **Knowledge Owner**: Curriculum Hub
   - **Government Source**: Kemendikdasmen Standar Proses
   - **Validation Rules**: Minimum mandatory effective weeks and hour sums must equal expected totals.
   - **Payload**: `intraCurricularHoursPerYear`, `coCurricularHoursPerYear`, `totalHoursPerYear`, `effectiveWeeksPerYear`.

3. **`IntracurricularKnowledge`**
   - **Knowledge Owner**: Curriculum Hub
   - **Government Source**: Kemendikdasmen Struktur Kurikulum
   - **Metadata Alignment**: `kemendikdasmenAligned`, `deepLearningAligned`.
   - **Payload**: Array of subjects mapped to their hours, subject types, and `deepLearningMethodologies` tags.

4. **`CocurricularKnowledge`**
   - **Knowledge Owner**: Curriculum Hub
   - **Government Source**: Panduan Pengembangan P5
   - **Metadata Alignment**: `kemendikdasmenAligned`, `profilLulusanDimensions`.
   - **Payload**: Array of project themes, descriptions, and explicit array mapping to target **8 Dimensi Profil Lulusan**.

5. **`ExtracurricularKnowledge`**
   - **Knowledge Owner**: Curriculum Hub
   - **Government Source**: Permendikbud tentang Ekstrakurikuler
   - **Metadata Alignment**: `tujuhKebiasaan`.
   - **Payload**: Mandatory/Optional programs, and routines, mapped explicitly to the target **7 Kebiasaan Anak Indonesia Hebat**.

6. **`AcademicCalendarKnowledge`** (Existing)
   - Left entirely unmodified, preserving the existing master-data mappings.

### KNOWLEDGE REGISTRY
Created dedicated Enterprise Registry entries in `src/enterprise/knowledge/registry/CurriculumKnowledgeRegistryEntries.ts`.
- Registered each domain with its standard `EnterpriseKnowledgeType` signature.
- Mapped explicit `governmentPolicyTags` (e.g., `8 Dimensi Profil Lulusan`, `7 Kebiasaan Anak Indonesia Hebat`, `Deep Learning`) ensuring AI generation tasks and KSP assemblies recognize their context strictly.
- Mapped `capabilities` (e.g., `SUPPORTS_AI_DRAFT` for P5 planning).

### KNOWLEDGE RELATIONSHIPS
- **Intracurricular** $\rightarrow$ mapped to **Deep Learning**
- **Cocurricular (P5)** $\rightarrow$ mapped to **8 Dimensi Profil Lulusan**
- **Extracurricular** $\rightarrow$ mapped to **7 Kebiasaan Anak Indonesia Hebat**
