# D5.0 COCURRICULAR KNOWLEDGE DOMAIN IMPLEMENTATION

## 1. Objective
Implement the `CocurricularKnowledge` domain to officially replace legacy P5 terminology and integrate "Kokurikuler" directly into the curriculum document engine.

## 2. Implementations

### Knowledge Model
- Created `CocurricularKnowledge.ts`.
- Included programmatic definitions for `programIdentity`, `objectives`, `targetLearners`, `activities` (as an array of objects), `assessment`, `reflection`, and `supportingDocuments`.
- Replaced all legacy terminology (e.g. P5) with strict references to Kokurikuler.

### Workspace
- Updated `CurriculumHubModule.tsx` to include an enterprise editor for Cocurricular (Kokurikuler) configuration.
- Features dynamic rows for adding, editing, and removing specific activities without limits.

### Adapter
- Created `CocurricularAdapter` within `CurriculumAdapter.ts` to seamlessly interpret and normalize the `rawCocurricular` configuration structure.
- Injects standard Kemendikdasmen-aligned fallback text for the general Kokurikuler structure.

### Assembler
- Altered `KspDocumentAssembler.ts` to instantiate `CocurricularKnowledge` using normalized state.
- Injected `cocurricularPayload` as a parameter to the `buildKspBab3Section` document builder.

### Builder
- Prepared `KspBab3Structure.ts` to generate a dynamic section dedicated to "Kokurikuler".
- Dynamically renders a comprehensive Activities Table mapping Name, Phase, Time, and Description.
- Automatically appends minimal contextual narrative for assessment and reflection.

## 3. Government Fidelity
- Hard-deprecated any mention of "P5".
- Utilized purely "Kokurikuler" structure, incorporating references to Dimensi Profil Lulusan and 7 Kebiasaan Anak Indonesia Hebat.

## 4. Regression Verification
- Extracurricular domain intentionally remains untouched as per boundary constraints.
- Verified successful `npm run lint` and `npm run build` operations with zero degradation to previous domains.

## FINAL DECISION
**GO**
Cocurricular is now successfully integrated into TAMPUYAK. Schools can freely input unlimited activities and assessment data directly through the UI, dynamically producing the canonical BAB III Kokurikuler segment.
