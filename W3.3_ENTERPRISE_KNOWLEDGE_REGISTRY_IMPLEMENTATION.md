# W3.3 ENTERPRISE KNOWLEDGE REGISTRY IMPLEMENTATION

## 1. FILES CREATED
- `src/enterprise/knowledge/types/EnterpriseKnowledgeDomain.ts`: Enum defining domains like `SCHOOL_PROFILE`, `CURRICULUM`, `ASSESSMENT`.
- `src/enterprise/knowledge/types/EnterpriseKnowledgeCategory.ts`: Enum defining categories like `PROGRAM`, `GUIDELINE`, `POLICY`.
- `src/enterprise/knowledge/types/EnterpriseKnowledgeCapability.ts`: Enum for capabilities such as `SUPPORTS_TEMPLATE`, `SUPPORTS_WIZARD`, `SUPPORTS_AI_DRAFT`.
- `src/enterprise/knowledge/types/EnterpriseKnowledgeType.ts`: Interface modeling the core structure of a Knowledge Type.
- `src/enterprise/knowledge/registry/EnterpriseKnowledgeRegistry.ts`: Singleton registry managing `EnterpriseKnowledgeType` registration and retrieval.
- `src/enterprise/knowledge/service/EnterpriseKnowledgeService.ts`: Service class providing query, filter, and search logic over the registry.

## 2. REGISTRY STRUCTURE
The Enterprise Knowledge Registry (EKR) is designed as a centralized catalog. It stores instances of `EnterpriseKnowledgeType` mapping out every permissible knowledge asset type within the system without hardcoding instances into application logic.

## 3. KNOWLEDGE DOMAINS & CATEGORIES
Domains act as the high-level business area (`SCHOOL_PROFILE`, `CURRICULUM`, `GOVERNANCE`), while Categories act as the structural format of the asset (`PROGRAM`, `POLICY`, `SOP`, `TEMPLATE`). This matrix allows exact classification of assets like a "Curriculum Program" or a "Governance SOP".

## 4. CAPABILITIES
Assets are no longer treated uniformly. `EnterpriseKnowledgeCapability` specifies precisely what an asset type supports:
- Does it support templates?
- Can it use a guided wizard?
- Is it versionable?
- Does it support AI drafting?

## 5. GOVERNMENT TAG STRATEGY
The `governmentPolicyTags` field is a string array designed to hold fluid metadata tying a knowledge type to current regulations, e.g., "Kemendikdasmen", "Deep Learning", "8 Dimensi Profil Lulusan". This enables filtering compliance requirements as policies evolve.
