# D3.0 LEARNING ORGANIZATION KNOWLEDGE DOMAIN IMPLEMENTATION

## 1. Objective
Establish the `LearningOrganizationKnowledge` domain as the parent knowledge domain for specialized curriculum components (Intracurricular, Cocurricular, and Extracurricular).

## 2. Implementations

- Created `LearningOrganizationKnowledge.ts`.
- Included fields: `educationalPhilosophy`, `learningPrinciples`, `implementationStrategy`, `responsibleUnit`, `targetLearners`, `assessmentApproach`, and `supportingDocuments`.
- Implemented deterministic `validate()` to ensure required fields are present.

### Workspace
- Updated `CurriculumHubModule.tsx` to include an editor for the Learning Organization parameters.
- Textareas and inputs map directly to the `LearningOrganizationKnowledge` payload.

### Adapter
- Implemented `LearningOrganizationAdapter` inside `CurriculumAdapter.ts`.
- Normalizes incoming `rawLearningOrganization` state from the workspace into standard knowledge structures.

### Assembler
- Updated `KspDocumentAssembler.ts` to process and construct `LearningOrganizationKnowledge`.
- Injected `learningOrganizationPayload` into the `buildKspBab3Section` builder.

### Builder
- Prepared `KspBab3Structure.ts` to consume `LearningOrganizationKnowledge`.
- Added dynamic "Pendekatan Pembelajaran" paragraphs using the philosophy, principles, strategy, and assessment approach provided by the knowledge domain.
- Verified that Intracurricular, Cocurricular, and Extracurricular specifics were intentionally omitted.
