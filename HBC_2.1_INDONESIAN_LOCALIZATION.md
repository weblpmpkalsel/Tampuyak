# HBC 2.1: Indonesian Localization

## Objective
Remove every remaining English technical label from the Enterprise Workspace and ensure the application speaks entirely in Bahasa Indonesia.

## Localization Summary
- **Workspace Module Registry**: Localized all module labels (e.g., 'School Profile' -> 'Profil Satuan Pendidikan', 'Administrative Metadata' -> 'Administrasi Dokumen').
- **Dashboard Module**: Translated header and welcome messages to "Beranda Enterprise".
- **Profile Module**: Localized all school identity fields, VMT titles, and characteristic categories.
- **Administrative Metadata Module**: Localized all signatory labels, document fields, and placeholders.
- **Document Library Module**: Translated sidebar filters, lists, and document card details (including references and version metadata).
- **Student Pedagogical Profile Module**: Localized learning needs (Visual -> Visual, Auditory -> Auditori), student potentials, and placeholders.
- **Curriculum Hub Module**: Translated Intracurricular and Cocurricular categories, subject names, phase targets, and assessment strategies.
- **Learning Planning Module**: Localized Principles, Approach, and Assessment policies.
- **Evaluation Hub Module**: Translated Evaluation Mechanisms, Schedules, Responsible Parties, and Continuous Improvement labels.
- **Professional Development Module**: Localized policies and buttons.
- **Compliance Center Module**: Translated "Compliance Center" to "Pusat Kepatuhan" and "Future Module Placeholder" to "Tempat Modul Masa Depan".
- **UI Elements**: Converted all action buttons ("Add", "Remove", "Preview") to "Tambah", "Hapus", "Pratinjau".

## Result
No English labels remain inside the production Workspace. The UI language is now understandable by Headmasters, Teachers, and School Operators.
