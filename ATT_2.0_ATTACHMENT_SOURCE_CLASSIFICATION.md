# ATT-2.0 ATTACHMENT SOURCE CLASSIFICATION

## MISSION
Classify every attachment based on its source (Generated vs Manual) to ensure users do not attempt to manually upload documents that are generated by the Enterprise Workspace.

## IMPLEMENTATION DETAILS
The `KSPAttachmentPanel` component has been updated to include a `type` field in the attachment mock data. The logic maps the attachment types to two primary sources:
*   **Manual**: External documents uploaded directly by the user (e.g., Kalender Pendidikan, SK Tim Pengembang Kurikulum).
*   **Generated**: System-authored documents derived from module data (e.g., Jadwal Pelajaran synced from Rapor Pendidikan, Berita Acara from Knowledge Builder).

The UI conditionally renders the Action buttons based on this `type`:
1.  **Generated Attachments:**
    *   Never display an "Upload" button.
    *   Display "Generate" (if missing) or "Refresh" (if available).
    *   Display a "Preview" button (disabled if missing).
2.  **Manual Attachments:**
    *   Display "Upload" (if missing) or "Replace" (if available).
    *   Display a "Preview" button (disabled if missing).

## REGRESSION RISK
**LOW**. The update only modifies the local UI array and rendering logic in `KSPAttachmentPanel.tsx`. No data fetching logic, PDF rendering engines, or validation core engines were touched.
