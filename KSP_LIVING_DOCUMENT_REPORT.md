# KSP LIVING DOCUMENT REPORT

## Concept
The KSP is not a static PDF to be printed once and forgotten. It is a Living Document that evolves.

## Living Document Features
- **Version Control**: Every revision generates a new minor/major version (e.g., v1.1, v2.0).
- **Synchronization**: As the parent document, any change in the KSP automatically triggers a recalculation in downstream documents (RKJM, RKT, RKAS).
- **Evaluation History**: The engine retains the reason for every revision, supporting the Continuous Improvement cycle (Perbaikan Berkelanjutan) required by Komponen 5.

## Conclusion
The KSP now functions as the dynamic, central operating system for the school's educational strategy.
