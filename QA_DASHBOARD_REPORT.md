This dashboard tracks the status of the Interactive Quality Assurance System (IQAS) across all GM-UAT documents.

## 2. QA Mode Integration
The application has been successfully shifted into Human-in-the-Loop Validation mode. The QA Panel has been added to the Document Workspace interface. It allows the human reviewer to:
- Mark sections as PASS/WARN/FAIL
- Adjust severity levels (Critical, High, Medium, Low)
- Record findings and comments
- Track remaining vs. reviewed pages
- Export QA findings natively as a JSON file
