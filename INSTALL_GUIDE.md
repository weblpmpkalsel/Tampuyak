# TAMPUYAK OS - Install Guide

## Chrome / Edge (Desktop)
1. Open TAMPUYAK OS.
2. Click the install icon in the URL bar, or open the menu and select "Install TAMPUYAK OS".
3. The app will launch in a standalone window, offering a native desktop experience without browser chrome.

## Android
1. Open in Chrome for Android.
2. An automatic "Add to Home Screen" prompt will appear.
3. Once installed, it behaves like a native application with an immersive splash screen and edge-to-edge display.

## iOS
1. Open in Safari.
2. Tap "Share" > "Add to Home Screen".
3. Launches as a standalone application.
