# KSP Gold Release: Phase 3 - Official Table of Contents Implementation

## 1. Table of Contents Mapping Report
The official Education Office Table of Contents (Daftar Isi) is mapped strictly into the Enterprise Canonical Document semantic structure. It acts as an automated, structural index of the document. Adhering to the rule "Canonical Document stores hierarchy only," the TOC does not contain hardcoded page numbers or manually typed section prefixes (e.g., "BAB I").

**Mapped Structural Components:**
- **Title ("DAFTAR ISI"):** Mapped to a Level 1 Heading.
- **Section Links:** Each document section is mapped to a `ParagraphBlock` containing a `LinkNode` that points to the section's deterministic ID.
- **Heading Links:** Sub-headings within sections are extracted and mapped to `LinkNode`s.
- **Hierarchical Grouping:** The hierarchy is structurally preserved by wrapping each Section and its corresponding Headings within a semantic `ContainerBlock`.

## 2. Automation & Resolution Traceability
- **Automatic Hierarchy:** The structure is dynamically generated by parsing the `DocumentSection[]` array. Any structural change in the document instantly updates the TOC hierarchy.
- **Automatic Section Numbering & Pagination:** The Canonical Document strictly omits all numbering and page calculation. Downstream Publishers intercept the TOC section, follow the semantic `LinkNode` targets, calculate their exact physical layout pages, and inject the correct pagination and chapter enumerations (e.g., "BAB I", "A.", "1.").
- **No Manual Numbering:** By storing only the raw text (e.g., "Pendahuluan") and relying on the Publisher for numbering formatting, the Canonical Document remains perfectly presentation-agnostic.
