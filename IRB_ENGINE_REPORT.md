# IRB ENGINE REPORT

## Architecture
The IRB (Identifikasi, Refleksi, Benahi) Engine automates the core analytical workflow required by the Ministry of Education for School Planning.

## Implementation Workflow
1. **Identifikasi:** Directly pulls the Weakness indicator objects from the SWOT Engine.
2. **Refleksi:** Extracts the linked `RootCause` array generated by the Root Cause Engine.
3. **Benahi:** Extracts the `recommendations` array bound to the specific indicator.
4. **Rationale (Education Reasoning Engine):** Automatically formulates the "Why" string. E.g., *"Karena capaian Kemampuan Literasi masih Merah (45), maka akar masalah kurangnya optimalisasi harus diselesaikan."*

The output is presented in a structured matrix within the UI, demonstrating a perfect, unbreakable chain of logic from raw score to strategic intervention.
