## 2. NAVIGATION STRUCTURE
The Enterprise Workspace introduces a dedicated two-pane layout:
- **Left Pane (Module Navigation)**: Dynamically rendered from the `WorkspaceModuleRegistry`. Future modules are tagged with `WIP` badges.
- **Right Pane (Content Container)**: Dynamically mounts the selected module component.

This workspace is accessible via a new dedicated button `Workspace Enterprise` in the global `Tampuyak OS` sidebar, positioned directly beneath the legacy `Data Sekolah` button.

## 3. MODULE REGISTRY
The `WorkspaceModuleRegistry` establishes an extensible pattern. Future sprints will simply append new objects to this registry and provide the actual implementations, without touching the shell architecture.
