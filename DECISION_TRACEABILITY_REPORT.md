# Decision Traceability Report

## Traceability Mandate
Tampuyak OS enforces absolute traceability. No budget allocation, objective, or program can exist without a clear, unbroken lineage linking it to an educational need and a regulatory standard.

## The Traceability Chain (Lineage Example)

1. **Origin (Evidence):** Rapor Pendidikan - Indikator A.1 (Literasi) skor 55 (Merah).
2. **Diagnosis (Root Cause):** Kurangnya kompetensi pedagogik guru dalam literasi baca tulis.
3. **Knowledge Constraint:** Permendikbudristek No. 63/2022 (BOS Guidelines) & SNP Standar PTK.
4. **Strategy (RKJM):** Meningkatkan kompetensi pedagogik guru melalui pengembangan keprofesian berkelanjutan.
5. **Tactic (RKT):** In-House Training (IHT) Strategi Literasi Lintas Mata Pelajaran (Tahun 1).
6. **Execution (RKAS):** Kode Kegiatan `04.06.05` - Pelatihan Peningkatan Kompetensi Guru (Literasi).
7. **Implementation:** Pelaksanaan IHT pada bulan Agustus 2024.
8. **Monitoring:** Laporan Supervisi Akademik Guru Pasca-IHT.
9. **Evaluation:** Kenaikan skor A.1 pada Rapor Pendidikan tahun berikutnya.

## Engine Validation
The Traceability Engine runs continuous validation across the planning graph.
- If an RKAS code is added manually without a parent RKT and Root Cause, it is flagged as an "Orphaned Budget Item".
- If an RKJM objective does not target a weak Rapor indicator, it is flagged as "Unaligned Strategy".

## Impact
This strict traceability ensures that every Rupiah spent and every hour allocated by the school directly contributes to resolving verified educational deficits, making the school's planning process highly defensible during audits and accreditations.
