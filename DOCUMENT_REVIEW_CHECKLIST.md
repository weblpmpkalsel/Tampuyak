# Document Review Checklist

## Automated Audit Protocol
Every official document (KSP, RKJM, RKT, RKAS) is evaluated against this comprehensive checklist:

### 1. Data Integrity
- [x] No missing identity fields (NPSN, Name).
- [x] No unresolved `{VARIABLES}` in the text.
- [x] No orphaned activities without a parent program.
- [x] Consistent academic years across all tables.

### 2. Narrative & Structure
- [x] Every chapter begins with an introduction.
- [x] Every table has a preceding explanation and following interpretation.
- [x] No isolated bullet lists without context.
- [x] Paragraph length and richness meet administrative standards.

### 3. Reasoning & Traceability
- [x] Every RKAS item traces back to a specific Rapor Pendidikan indicator.
- [x] Root cause analysis explicitly links to the chosen intervention.
- [x] Expected outcomes are measurable and documented.

### 4. Legal & Compliance
- [x] All regulatory references are valid and up-to-date.
- [x] Terminology strictly adheres to the Master Education Platform dictionary.

## Final Certification
**PASS** - The automated checklist is actively enforced by the DRE.
